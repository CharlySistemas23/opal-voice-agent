# Opal Voice Agent

Voice command center 24/7 para operación remota del sistema POS Opal.

Conecta Twilio con OpenAI Realtime + gbrain. Bilingüe (es/en).

## Tools

- `take_note` — nota al brain
- `schedule_callback` — programar callback
- `get_system_status` — health del POS
- `get_sales_today` — ventas del día
- `restart_backend` — reinicia POS via Railway
- `create_issue` — issue en GitHub
